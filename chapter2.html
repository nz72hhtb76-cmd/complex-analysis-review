第二章 · 后续内容

复指数与初等函数

把实变量公式推广到复数时，最值得留意的是周期性、多值性和定义域。以下内容对应第二章课件的初等函数部分。

复指数函数

ex+iy=ex(cosy+isiny)

实部 x 决定模长 eˣ，虚部 y 决定幅角。因正弦、余弦以 2π 为周期，eᶻ 的周期为 2πi；它在整个复平面解析且导数为自身，也永远不等于零。

补充例题：解 eᶻ = 1

设 z = x + iy。模长 eˣ = 1 得 x = 0；幅角 y = 2kπ。因此全部解为 z = 2kπi，其中 k 为整数。

补充例题：解 eᶻ = −2

令 z = x + iy。比较模长，eˣ = 2，故 x = ln 2；比较幅角，y = (2k+1)π。因而全部解为

z=ln2+(2k+1)πi,k∈ℤ

检查：指数函数每增加 2πi 取值不变，因此不能漏掉整数 k。

复对数与分支

对于非零复数 z，幅角相差 2kπ 的值都代表同一点，因此复对数通常是多值的：

logz=ln|z|+i(argz+2kπ),k∈ℤ

这里沿用课件记号，arg z 表示主幅角，其取值范围为 (−π, π]；所有幅角为 arg z + 2kπ。取 k = 0 可得到主值 Log z；要讨论解析分支，则需要在适当的开区域连续选择幅角，例如去掉非正实轴后所得的主支。不要把多值对数当成处处单值函数。

补充例题：求 log(−1) 的所有值

模长为 1，幅角为 π + 2kπ，因此 log(−1) = (2k + 1)πi，k ∈ ℤ。主值为 πi。

复幂、三角与双曲函数

复幂可由 zᵃ = ea log z 定义，一般也可能多值；选定对数的解析分支后才能得到对应的单值解析分支。正弦和余弦可以通过指数定义：

sinz=eiz−e−iz2i,cosz=eiz+e−iz2

同样，sinh z = (eᶻ − e⁻ᶻ)/2、cosh z = (eᶻ + e⁻ᶻ)/2。它们由整函数构成，在整个复平面解析。复数范围内不要直接套用“正弦值绝对值不超过 1”的实数结论。

补充例题：解 sin z = 0

由指数定义，sin z = 0 等价于 eⁱᶻ = e⁻ⁱᶻ，即 e²ⁱᶻ = 1。于是 2iz = 2kπi，得到所有解 z = kπ，k ∈ ℤ。

反三角函数：为什么是多值的？

复正弦、余弦具有周期性，同一个函数值通常对应多个原像，所以反函数一般是多值的。比如 sin z = 0 有无穷多个解 kπ；若题目要求单值反函数，必须指定定义域与分支。用对数和平方根表示反三角函数时，这些分支的选择也必须相互配合。

第二章 · 调和函数与复势

从解析函数看调和函数

二元实函数具有连续二阶偏导，且满足拉普拉斯方程时称为调和函数：

∇2u=∂2u∂x2+∂2u∂y2=0

若 f = u + iv 在区域内解析，则 u、v 都是调和函数，且满足 C–R 方程。反过来，给定调和函数要寻找共轭调和函数时，先检查所在区域；在单连通区域内可得到全局共轭调和函数，其他区域可能只在局部成立。

补充例题：已知 u = x² − y²，求解析函数

先算 uₓₓ + uᵧᵧ = 2 − 2 = 0。C–R 方程给出 vᵧ = 2x、vₓ = 2y；积分并核对可得 v = 2xy + C。因此 f(z) = z² + iC，C 为实常数。

补充例题：已知 u = eˣ cos y，求共轭调和函数

先算 uₓₓ = eˣ cos y、uᵧᵧ = −eˣ cos y，和为零，因此 u 调和。由 C–R 方程 vᵧ = uₓ = eˣ cos y，对 y 积分得 v = eˣ sin y + φ(x)。再用 vₓ = −uᵧ = eˣ sin y，可得 φ′(x) = 0。

v=exsiny+C,f(z)=ez+iC

其中 C 是实常数；题目若给定一个虚部值，就能确定 C。

平面场与复势

课件还把平面向量场与解析函数联系起来：在适用的无源、无旋区域内，可以用势函数与流函数的组合描述二维场。不同教材对流函数及复速度的正负号约定可能不同，计算前应先按题目给出的定义确认方向与符号。等势线和流线在梯度非零的正规点相互正交。

做题路线：先判断区域和调和条件，再用 C–R 方程求共轭函数，最后利用给定初值确定常数。

第二章 · 自编测验

复习检查

1. eᶻ = 1 是否只有 z = 0 一个解？

不是。全部解为 2kπi，k ∈ ℤ。

2. log(−1) 的主值是多少？

按 arg z ∈ (−π, π] 的约定，主值为 πi。

3. u = x² + y² 是调和函数吗？

不是；uₓₓ + uᵧᵧ = 4，不等于 0。

4. eᶻ 可以等于 0 吗？

不能。其模为 eˣ，始终严格大于 0。

5. 求 sin(i) 的值。

由指数定义，sin(i) = (e⁻¹ − e)/(2i) = i sinh(1)，它不是实数范围的正弦值。

6. log(−i) 的所有值是什么？

其模为 1，按主幅角 (−π,π]，幅角为 −π/2 + 2kπ，所以各值为 i(−π/2 + 2kπ)，k 为整数。

7. 若 u 和 v 满足 C–R 方程，vₓ 等于什么？

vₓ = −uᵧ；另一个方程是 vᵧ = uₓ。仅在一点满足方程还不足以保证可导。

8. 每个调和函数都在任意区域存在全局共轭调和函数吗？

不一定。单连通区域内可以找到全局共轭；有孔区域可能只有局部分支。

第二章 / 补充例题

复势：等势线和流线怎样联系？

本例使用约定：复势 F=φ+iψ，速度向量取 v=∇φ。其中 φ 是势函数，ψ 是流函数。不同题目可能采用相反的符号约定，务必先看题目定义。

例：给定复势 F(z)=z²，求势函数、流函数并说明两组曲线的关系

第一步：拆开实部和虚部。代入 z=x+iy，展开：

F(z)=x2−y2+i2xy,φ=x2−y2,ψ=2xy

第二步：写出曲线。等势线是 φ=c，即 x²−y²=c；流线是 ψ=k，即 2xy=k，c 和 k 都是实常数。

第三步：计算梯度。等势线和流线在正规点的法向量分别是：

∇φ=(2x,−2y),∇ψ=(2y,2x)

两梯度的点积是 4xy−4xy=0。因此在原点以外，两组曲线相交时互相垂直。速度 ∇φ 与 ∇ψ 垂直，所以速度沿着 ψ=k 的流线方向。原点处两梯度均为零，不能据此讨论交角。

易错对照：在本例约定下，速度向量写为 (φₓ,φᵧ)，其复数表示是 φₓ+iφᵧ=2z̄；而 F′(z)=2z。二者互为共轭，不应直接混同。

第二章 / 补充例题

反三角函数：先选分支，再算值

由于复正弦函数有周期，一个值一般有多个原像。若用对数与平方根写反函数，它们也需要一致地选定分支；以下只介绍常用主支。

在去掉实轴上两条射线 (−∞,−1] 和 [1,∞) 后的区域内，取在 z=0 附近等于 1 的平方根分支，并取主对数，可定义主支：

arcsinz=−iLog(iz+1−z2)

这个分支在 z=0 的值为 0；对 −1<x<1，它与熟悉的实数反正弦一致。这里的定义域是选定的开区域，端点及分支切割线上不能直接把解析分支公式当成处处适用。

例：求主值 arcsin(i)，并比较方程 sin w=i 的全部解

第一步：令 z=i，则 1−z²=2，选定的平方根为 √2。主对数的自变量为 i·i+√2=√2−1，是正实数。

第二步：因 (√2−1)(√2+1)=1，故 ln(√2−1)=−ln(√2+1)。于是：

arcsin(i)=iln(1+2)

第三步：设 a=ln(1+√2)，则 sinh a=1，直接代回得 sin(ia)=i。方程的全部解还有另一组，合起来是 w=ia+2kπ 或 w=π−ia+2kπ，其中 k 为整数。

易错对照：主值只是选定分支上的一个值，不代表原方程只有一个解；将平方根两种值和对数各个值随意组合，也可能混淆分支。

易错判断：arcsin(sin z)=z 对所有复数都成立吗？

不成立。比如 z=π 时，sin π=0，但主支 arcsin(0)=0≠π。只有在选定反函数对应的适当取值范围内才能消去。
