柯西–古萨定理：闭路积分为什么为零

本讲核心不是背结论，而是先核查函数的解析区域与路径的关系。

1. 定理与条件

若 f 在单连通域 D 内解析，则沿 D 内任意分段光滑闭曲线积分为零。对简单闭曲线，常用的充分条件是：函数在曲线及其内部的某个开邻域解析。

∮Cf(z)dz=0

直观上，解析性让相邻小区域的边界贡献互相抵消，最后只剩外边界。严谨证明不能凭图直接代替；柯西–古萨定理也不要求额外假设导函数连续。

2. 使用前四问

  1. 路径真的闭合吗？
  2. 被积函数在哪里不解析？分母为零时是否能先约去？
  3. 曲线和围住的内部是否都包含在解析区域中？
  4. 参数方向虽对零值无影响，对其他积分是否会影响符号？
补充例题 1：正向 |z|=2，积分 (z²+sin z) dz

z² 与 sin z 都是整函数，圆及内部没有奇点，曲线又闭合，所以积分为 0。无需将圆参数化逐项积分。

补充例题 2：正向 |z|=1，积分 dz/z

1/z 在原点不解析，而原点在圆内，定理的充分条件不满足；此时不能说结果为零。直接参数化 z=eⁱᵗ 可得积分 2πi。注意：条件不满足只能说明该定理不能直接使用，不能单凭此就断言积分一定非零。

练习：1/(z−3) 沿 |z|=2 的积分？

3 在圆外，函数在圆及内部某开邻域解析，故为 0。

易错：“曲线上有定义”不等于“曲线及内部解析”；“一条闭路积分恰好为 0”也不能反推出函数在整个区域解析。

补充例题 3：∮(z+1)/(z−3) dz，|z|=2

第一步，分母仅在 z=3 为零；3 位于圆外。第二步，被积函数在闭圆盘某邻域解析。第三步，路径闭合，因此按柯西–古萨定理积分为 0。分子是否为多项式并不足以决定结果，必须结合分母。

从定理到路径变形

把区域切成许多小块，内部相邻的公共边分别按相反方向出现，因此相互抵消。若存在一个不解析点，就不能直接把含该点的小块套进同一个论证；下一讲会学习怎样挖去该点。

自测 1：在区域内解析的函数，沿闭合路径的积分一定为 0 吗？

要看区域和路径：如果区域单连通，则为 0；有孔区域不一定，例如去心平面上的 1/z 绕原点一圈。

自测 2：正向 |z|=1 上 ∮z³ dz？

z³ 是整函数，闭路积分为 0。

自测 3：∮dz/z 在原点外的圆周上，能否因为曲线上可导就说为 0？

不能。应检查圆内；若圆包围 0，则实际值为 2πi。
