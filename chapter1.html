第一章 / 复数与复变函数

从一个点，认识复数

先把复数看成平面上的点，再用长度和角度理解运算。本章按照课件的六个小节复习，例题注明出处，自测题为补充。

1.1 / 代数运算

实部、虚部与共轭

复数写成 z=x+iy，其中 x、y 为实数，i² = −1。实部是 x，虚部是 y，虚部不包含 i。两个复数相等，当且仅当实部、虚部分别相等。

加减时分别计算实部与虚部；相乘先展开，再用 i² = −1；相除时将分子、分母同乘分母的共轭。模与共轭为：

z¯=x−iy,|z|=x2+y2,zz¯=|z|2
课件例 7（第 48 页）：计算 (5−5i)/(−3+4i)

分子分母同乘 −3−4i。分母为 25，分子为 −35−5i，故结果为 −75−15i。

复数不能像实数一样建立与四则运算相容的大小顺序；但其模是非负实数，可以比较。

1.2 / 几何表示

复平面与极坐标

点 (x,y) 和从原点指向该点的向量都表示 z。共轭对应关于实轴的镜像；模 |z| 是点到原点的距离。对于 z ≠ 0，令 r=|z|，θ 为从正实轴量起、以逆时针为正的有向角：

z=r(cosθ+isinθ)=reiθ

θ 与 θ+2kπ 表示相同方向。课件约定幅角主值在 (−π,π]；零的幅角无定义。

课件例 2（第 27 页）：把 −1+√3 i 写成指数式

模为 2，点在第二象限，幅角主值为 2π/3，因此 z=2e2πi3。

动手转一转：幅角与复平面

调节角度，观察单位复数的实部和虚部。

1.3 / 乘幂与方根

乘法是缩放加旋转

两个复数相乘：模相乘、幅角相加；相除：模相除、幅角相减（除数非零）。这使乘方与求根更直观。

(cosθ+isinθ)n=cosnθ+isinnθ

这是课件第 42 页的棣莫弗公式。对非零复数 a = reⁱᶿ，令 n 为正整数；方程 zⁿ = a 恰有 n 个不同的根：

zk=rneiθ+2kπn,k=0,1,…,n−1

根均匀分布在以原点为中心的圆上；若 a=0，唯一不同的根是 0。

补充例题：求 z³=1 的全部根

取 r=1、θ=0、n=3，得到 1、−1/2+√3 i/2、−1/2−√3 i/2。三个点相隔 120°。

课件例 9（第 50 页）：求 5+12i 的平方根

设根为 x+iy，比较实部和虚部得 x²−y²=5、2xy=12。解得两个根为 ±(3+2i)；直接平方可以检查。

1.4 / 区域

邻域、边界和区域

以 z₀ 为中心、半径 ε 的邻域是 |z−z₀|<ε；去心邻域还去掉中心点，即 0<|z−z₀|<ε。内点附近能画出完全落在集合内的小圆；边界点的每个邻域既碰到集合内的点，也碰到集合外的点。

区域是连通的开集。开集中的每一点都是内点；连通可理解为区域内任意两点能用完全位于区域内的折线相连。圆盘是单连通的；去掉中心的圆盘有一个洞，是多连通的。沿边界正向走时，区域始终在左边，因此环域外圈逆时针、内圈顺时针。（课件第 59—68 页）

课件例 14（第 70 页）：|z−1|+|z+1|<4 是什么区域？

到 1 和 −1 的距离之和小于 4，边界是以这两点为焦点的椭圆，因此是椭圆内部，有界且单连通，边界不属于该区域。

1.5—1.6 / 函数与极限

复变函数是一种映射

写 z=x+iy、w=f(z)=u(x,y)+iv(x,y)。它把 z 平面的点映到 w 平面：例如 w=iz 将每个点绕原点逆时针旋转 90°；w=z̄ 是关于实轴的反射。（课件第 72—86 页）

极限和连续

当 z 沿任意路径趋近 z₀ 时，如果 f(z) 都趋向同一个有限复数 A，就有下式。实部与虚部同时分别趋向 A 的实部和虚部，是极限存在的充要条件。

limz→z0f(z)=A

如果该极限等于 f(z₀)，就称 f 在 z₀ 连续。两条路径的极限不同足以否定极限存在；几条路径结果相同不足以证明存在。

课件例 20（第 90 页）：求 z→1+2i 时 z² 的极限

多项式连续，直接代入：(1+2i)²=−3+4i。

课件例 21（第 92 页）：Re(z)/|z| 在 z→0 时有极限吗？

沿正实轴趋近时取值为 1；沿正虚轴趋近时取值为 0。两条路径结果不同，所以极限不存在。

第一章 / 自编测验

学完试一试

1. z=3−4i 的虚部是多少？

−4；虚部是实数，不是 −4i。模为 5。

2. arg(−1) 在本课件约定下是多少？

π。主值范围是 (−π,π]；全部幅角是 π+2kπ。

3. 圆环 1<|z|<2 是单连通的吗？

不是。它中间有洞，是多连通区域；不包含两条边界圆。

4. 沿两条不同路径求出不同的极限，可以得出什么？

可以断定该复极限不存在。

5. z⁴=1 一共有几个不同的根？

四个：1、i、−1、−i，它们在单位圆上相距 90°。

第一章 / 补充例题

把关键步骤走一遍

先自己试算，再展开对照。以下题目为补充练习。

例 1：把 (1+2i)/(1−i) 化为代数形式

第一步：分子和分母同乘分母的共轭 1+i，让分母变为实数。

1+2i1−i=(1+2i)(1+i)(1−i)(1+i)

第二步：分母为 1−i²=2，分子为 1+3i+2i²=−1+3i。因此：

1+2i1−i=−12+32i

易错对照：只乘分母会改变原式；分子、分母必须同时乘以同一个非零复数。

例 2：求方程 z³=−8 的全部根

第一步：−8 的模为 8，取幅角 π，即 −8=8eiπ。求根时还要包括相差 2kπ 的幅角。

第二步：模开三次方得到 2，角度除以 3；取 k=0、1、2 得三个不同的根。

zk=2eiπ+2kπ3,k=0,1,2

依次化为代数形式：1+√3i、−2、1−√3i。三个根在半径为 2 的圆上间隔 120°；代回立方均为 −8。

易错对照：只取主幅角再除以 3 只能找到其中一个根，不能漏掉其余两个。

例 3：判断 z̄/z 在 z→0 时是否有极限

函数在去心邻域有定义。第一步：沿正实轴 z=x→0，x>0，函数值为 x/x=1。

第二步：沿正虚轴 z=iy→0，y>0，函数值为 (−iy)/(iy)=−1。

两条路径得到不同结果，所以极限不存在。易错对照：找到两条路径相同只能提供线索；找到两条路径不同就足以否定极限。
