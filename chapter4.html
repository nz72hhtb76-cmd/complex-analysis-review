第四章 / 4.1

复数项级数：先看部分和

数列是一项项的数；级数是把它们依次相加。先算前 N 项的部分和，再让 N 越来越大。如果部分和有确定的极限，就说级数收敛，这个极限叫作和。

∑n=0Nan=SN，limN→∞SN=S

复数项级数收敛，当且仅当实部级数和虚部级数都收敛。如果模的级数收敛，就称原级数绝对收敛；绝对收敛一定收敛。反过来不一定。通项趋于 0 是必要条件，单靠它还不能断定收敛。

最常用的起点：等比级数

∑n=0∞zn=11−z，|z|<1

这个公式是后面求泰勒和洛朗展开的工具。注意：圆周 |z|=1 的点不能直接套用，需要单独判断。

课件例：求级数 ∑ 3i / 2ⁿ 的和（n 从 1 开始）

把 3i 提出来。实数等比级数 1/2＋1/4＋… 的和为 1，所以原级数的和为 3i。（第四章课件第 27 页）

第四章 / 4.2

幂级数与收敛圆

幂级数围绕中心 z₀ 展开。收敛半径 R 把平面分成圆内和圆外：圆内绝对收敛，圆外发散；圆周上的点逐点判断。R 可以是 0 或无穷大。

∑n=0∞an(z−z0)n

如果相邻系数的模之比有极限 L，且系数从某项起不为零，则 R=1/L（L=0 时 R=∞，L=∞ 时 R=0）。也可使用根值公式 R=1/limsup |aₙ|¹⁄ⁿ。圆内任意半径小于 R 的闭圆上，级数一致收敛；在收敛圆内可逐项求导、积分。

自编例：∑ n zⁿ 的收敛半径是多少？

系数相邻比 (n+1)/n 趋于 1，故 R=1。圆内收敛，圆外发散；|z|=1 时，通项 n zⁿ 的模为 n，不趋于 0，所以圆周也发散。

为什么有收敛圆？根值判别法考察第 n 项模的 n 次方根，约为 |z−z₀|·|aₙ|¹⁄ⁿ。它的上极限小于 1 时绝对收敛，大于 1 时通项不趋零；恰好等于 1 时，判别法不给结论，因此圆周必须另判。
补充例题一：比较两个极端收敛半径

① ∑ n!zⁿ：n 从 0 开始。相邻项的模之比为 (n+1)|z|。当 z≠0 时它最终大于 1 且趋于无穷，级数发散；z=0 时只有常数项，因此 R=0。

② ∑ zⁿ/n!：相邻项的模之比为 |z|/(n+1)，对每个固定 z 都趋于 0，故处处绝对收敛，R=∞。它的和是 eᶻ。

先固定 z 再令 n→∞；不要把相邻项比值中的 z 漏掉。

补充例题二：∑ zⁿ/n 的圆周为什么要逐点判断？

n 从 1 开始。系数相邻比 n/(n+1) 趋于 1，所以 R=1：|z|<1 时绝对收敛，|z|>1 时通项不趋于 0。

在 z=1，得到调和级数，发散；在 z=−1，得到交错调和级数，条件收敛但不绝对收敛。同一个圆周上两个点结论不同。

第四章 / 4.3

泰勒级数：用幂级数表示解析函数

函数在中心附近解析时，可把它写成关于 z−z₀ 的幂级数。系数来自该点的各阶导数；以 0 为中心时也称麦克劳林展开。

f(z)=∑n=0∞f(n)(z0)n!(z−z0)n

常用展开

ez=1+z+z22!+z33!+⋯，z∈ℂ
sinz=z−z33!+z55!−⋯
课件例：展开 1/(1−3z＋2z²)

分母分解为 (1−z)(1−2z)，再拆成 −1/(1−z)＋2/(1−2z)。对两个部分分别应用等比级数。

11−3z+2z2=∑n=0∞(2n+1−1)zn，|z|<12

两项同时成立需要 |z|<1/2。（第四章课件第 114–116 页）

泰勒展开的直觉：在解析圆盘内，函数能由其在中心点的各阶导数恢复。计算时不一定逐次求导；先识别等比、指数等基本展开，再代入和化简，通常更快。展开式的有效圆盘不能穿过函数真正的奇点。
补充例题三：以 z₀=1 为中心展开 1/(z+1)

第一步：令 w=z−1，把分母改写为 2+w，再提取 2：

1z+1=1211+z−12

第二步：把 −(z−1)/2 当作等比级数公比，得到：

1z+1=12∑n=0∞(−z−12)n,|z−1|<2

展开中心到奇点 −1 的距离为 2，和算出的半径一致。这里所有圆周点的公比模为 1，通项不趋零，故圆周均发散。

第四章 / 4.4

洛朗级数：环域里允许负次幂

如果中心点附近存在奇点，普通泰勒级数可能不够用。在函数解析的环域内，可以同时使用正次幂和负次幂；负次幂组成主要部分。相同函数在不同环域的展开可能不同，必须写出收敛区域。

f(z)=∑n=−∞∞an(z−z0)n
课件例：在 1<|z|<∞ 展开 1/(z²−1)

因为 |1/z²|<1，把分母写成 z²(1−1/z²)，再使用等比级数：

1z2−1=1z2+1z4+1z6+⋯

展开条件是 |z|>1。（第四章课件第 164 页）

补充例题：为什么同一函数在不同环域展开不同？

对 f(z)=1z(z−1)，先写成 −1/z + 1/(z−1)。若 0<|z|<1，把后一项写为 −1/(1−z)，得到：

f(z)=−1z−1−z−z2−⋯

若 |z|>1，改用 1/(z−1)=z⁻¹/(1−z⁻¹)，第一项恰好抵消，得到：

f(z)=1z2+1z3+⋯

关键是每次先看等比级数的公比模是否小于 1。

洛朗展开的直觉：在环域里，正次幂用来描述向外看仍解析的部分；负次幂可描述中心附近的奇性。先拆分函数，再根据公比的模小于 1 选择正幂或负幂，最后取各部分收敛范围的交集。
补充例题四：同一函数在两个环域的洛朗展开

以 0 为中心，展开 f(z)=1/[z(z−2)]。两个奇点分别在 0 和 2，先拆分：

1z(z−2)=−12z+12(z−2)

① 0<|z|<2：对第二项提取 −2，公比是 z/2；与第一项合并：

f(z)=−12z−∑n=0∞zn2n+2

② |z|>2：直接将原式改写为 z⁻²/(1−2/z)，公比 2/z 的模小于 1，故：

f(z)=∑n=0∞2nzn+2

内外环域的公比不同，表达式也不同；|z|=2 上有奇点，不能把它包括进环域。

自测 1：通项趋于 0 是否足以说明级数收敛？

不够。例如调和级数的通项 1/n 趋于 0，但级数发散。

自测 2：幂级数的收敛圆周是否一定收敛？

不一定。圆周点需要逐点检验。

自测 3：洛朗展开为什么必须写出环域？

同一个函数围绕同一中心，在不同的解析环域内可以有不同展开；每个展开都有自己的有效范围。

互动实验 · 级数

部分和怎样靠近极限？

调整公比和项数，观察从第 0 项加到第 N 项的等比级数。这里限制 |r|≤0.9，所以级数收敛。

负公比时，部分和会在极限两侧交替；项数越多，误差的绝对值趋向零。
