第五章 / 积分

留数定理：闭路积分转化为求和

设正向简单闭曲线 C 内只有有限个孤立奇点，函数在曲线上及其余内部点解析，那么积分等于曲线内部留数之和乘 2πi。奇点不能落在积分路径上。

∮Cf(z)dz=2πi∑Res(f,zk)

解题四步

  1. 找到全部奇点并画出积分路径。
  2. 只挑路径内部的奇点，判断各自阶数。
  3. 算各点留数并求和。
  4. 乘以 2πi；如果路径方向为顺时针，结果需变号。
自编例：沿 |z|=2 逆时针，积分 1/(z²+1)

奇点 i 和 −i 都在圆内；它们的留数分别为 1/(2i) 和 −1/(2i)，和为 0，所以积分为 0。关键是两个点都要算进去。

第四讲 / 完整步骤

先画图，再计算

  1. 列出奇点；若分子分母可约，先处理可去点。
  2. 标出积分方向和每个奇点与曲线的位置，位于曲线上的点不能直接用普通留数定理。
  3. 计算曲线内部各奇点留数之和。
  4. 正向乘 2πi，顺向相反则乘 −2πi。
补充例题：∮ dz/[z(z−1)]，|z|=2 正向

0 和 1 都在圈内，对应留数 −1 和 1，相加为 0，因此积分为 0。每个局部留数不为零，但总积分仍可因相互抵消而为零。

练习：同一函数沿 |z|=1/2 正向积分是多少？

只有 0 在内部，留数和为 −1，因此积分为 −2πi。

互动实验 · 留数

移动积分圈，看留数如何相加

被积函数取 f(z)=1/[z(z−1)]。绿色圆周沿逆时针方向，两个点分别是 0 和 1。改变圆心与半径，观察圈住的极点。

积分路径经过极点时，本实验所用的通常闭路积分不存在，不能套用留数定理。
