第一章 / 学习单元 3

乘法的旋转、乘方与开根

本单元范围：极坐标乘除、棣莫弗公式、n 次根。先读解释，再做例题，最后独立完成练习。

1.3 / 乘幂与方根

乘法是缩放加旋转

两个复数相乘：模相乘、幅角相加；相除：模相除、幅角相减（除数非零）。这使乘方与求根更直观。

(cosθ+isinθ)n=cosnθ+isinnθ

这是课件第 42 页的棣莫弗公式。对非零复数 a = reⁱᶿ，令 n 为正整数；方程 zⁿ = a 恰有 n 个不同的根：

zk=rneiθ+2kπn,k=0,1,…,n−1

根均匀分布在以原点为中心的圆上；若 a=0，唯一不同的根是 0。

补充例题：求 z³=1 的全部根

取 r=1、θ=0、n=3，得到 1、−1/2+√3 i/2、−1/2−√3 i/2。三个点相隔 120°。

课件例 9（第 50 页）：求 5+12i 的平方根

设根为 x+iy，比较实部和虚部得 x²−y²=5、2xy=12。解得两个根为 ±(3+2i)；直接平方可以检查。

乘法为什么对应旋转？

设两个非零复数分别有模 r₁、r₂ 和幅角 θ₁、θ₂。运用三角函数的和角公式，乘积的模为 r₁r₂，角为 θ₁+θ₂。特别地，乘以 i 的模不变、角增加 π/2，也就是逆时针旋转 90°；除以 i 则顺时针旋转 90°。

从角度相加到棣莫弗公式

把同一个单位复数相乘 n 次，每次增加 θ，因而第 n 次幂的角为 nθ。一般复数还要把模 r 乘 n 次。n 次根反过来求模和角：要先把原数全部可能的幅角 θ+2kπ 写全，再除以 n。

补充例题：解 z³=−8

−8 的模是 8，一个幅角是 π。设 z 的模为 ρ，幅角为 φ，则 ρ³=8、3φ=π+2kπ。故 ρ=2，φ=(π+2kπ)/3，取 k=0、1、2 得三个不同的根：

1+3i,−2,1−3i

它们位于半径 2 的圆上，彼此相隔 120°。依次代回三次方均为 −8。

零有唯一不同的 n 次根 0；非零复数有 n 个不同的 n 次根。求全部根不能只把主幅角除以 n。
练习 1：i²⁰²⁶ 等于什么？

i 的幂每 4 次循环一次，2026 除以 4 余 2，所以 i²⁰²⁶=i²=−1。

练习 2：方程 z⁴=1 有哪些根？

幅角分别为 0、π/2、π、3π/2，根为 1、i、−1、−i。

复数开方的两种方法

极坐标适合高次根；二次根也可以设 z=x+iy 后比较实部和虚部。解完需要回代，避免因平方产生多余解或漏掉一个根。

补充例题：解 z²=−2i

令 z=x+iy，比较实部、虚部得到 x²−y²=0、2xy=−2。故 y=±x；因 xy=−1，只可能 y=−x。于是 x²=1，得 z=1−i 或 z=−1+i。两根平方都等于 −2i。

练习：−1 的三个立方根的模分别是多少？

都为 1。因为若 z³=−1，则 |z|³=1，|z|=1；它们的角度相隔 2π/3。

深入讲解 / 根的完整性

为什么恰好有 n 个不同的根？

对 a=reⁱᶿ（r>0），设 z=ρeⁱᵠ。由 zⁿ=a 先得 ρⁿ=r；再由幅角只能相差 2kπ，得到 nφ=θ+2kπ。k 增加 n 后，φ 恰好多 2π，所以 k=0,…,n−1 给出全部不同方向。

zk=rneiθ+2kπn,k=0,…,n−1
分步例题（补充）：解 z⁴=−16

第一步，右侧模为 16，取幅角 π。第二步，根的模为 16 的四次方根 2，幅角为 (π+2kπ)/4，其中 k=0,1,2,3。第三步，四个角依次为 π/4、3π/4、5π/4、7π/4，对应根为 √2(1+i)、√2(−1+i)、√2(−1−i)、√2(1−i)。四个根相隔 π/2。

分步例题（补充）：计算 (1+i)⁸

先用代数法：(1+i)²=2i，所以 (1+i)⁴=−4，(1+i)⁸=16。也可从模 √2、幅角 π/4 看出八次方的模为 16、幅角为 2π。

自测：z²=9 有几个根？

两个不同的根 3 和 −3。实数平方根中的非负主值 3，不能替代方程的全部解。

自测：z⁴=0 有几个不同根？

只有 0。非零复数的 n 次根才是 n 个不同点；重数与不同根的个数是不同概念。

自测：乘以 −i 的几何效果是什么？

模不变，幅角减少 π/2，即顺时针旋转 90°。
