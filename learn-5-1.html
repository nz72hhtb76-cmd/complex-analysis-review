第五章 / 基础

孤立奇点：先看函数在点附近怎样变化

本章依据第五章课件的三部分整理，课件例题已查看原页并独立核算；其余例题和测验为补充编写。课件共 201 页，本页是重点复习，不代表已逐页覆盖。

如果函数在点 z₀ 的某个去心邻域内解析，但在 z₀ 处不解析，z₀ 是孤立奇点。判断它的类型，可看该点附近洛朗展开的负幂部分。

可去奇点

没有负幂项；补定义合适的函数值后可以解析。

极点

只有有限个负幂项。最高负幂为 −m，就称 m 阶极点。

本性奇点

有无穷多个负幂项。例如 e^(1/z) 的原点。

若 z₀ 是 m 阶极点，也可判断：去心邻域上 (z−z₀)ᵐf(z) 在该点有有限非零极限。

第一讲 / 方法

先排除“不是孤立奇点”的情形

找一个半径 r，使 0<|z−z₀|<r 内函数解析；能做到，才可以用洛朗负幂判断孤立奇点。若其他奇点无限靠近 z₀，任何去心邻域都避不开它们，不能直接做孤立奇点三分类。

三种常用判别

  1. 有限极限：若 f 在去心邻域解析且趋于有限值，可去；补上该极限即解析。
  2. 极点：若 |f(z)|→∞，则为极点；要判阶，可找最小正整数 m，使 (z−z₀)ᵐf(z) 趋向非零有限值。
  3. 本性奇点：既非可去又非极点时，为本性奇点；例如洛朗展开含无穷多个负幂。
补充例题：判断 (eᶻ−1)/z² 在原点的类型

先展开 eᶻ−1=z+z²/2+z³/6+⋯。除以 z² 得 1/z+1/2+z/6+⋯，所以原点只有一个负幂，是一阶极点。若只看分母 z² 就说二阶，会忽略分子在原点的一个零点。

补充例题：sin z/z 的 0 点有定义吗？

原式在 0 未定义，但极限为 1，故 0 是可去奇点。补定义 f(0)=1 后，延拓函数在 0 解析。

练习：e¹⁄ᶻ 的 0 点为什么不是极点？

其洛朗展开含 1/z、1/z²/2!、1/z³/3! 等无穷多个负幂，故 0 是本性奇点。
