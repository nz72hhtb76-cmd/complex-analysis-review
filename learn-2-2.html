第二讲：解析性与奇点

一点可导、邻域解析、区域解析及奇点

先区分三个层次

一点可导只检查该点的差商；在 z₀ 解析，要求存在 z₀ 的某个开邻域，使函数在邻域内每一点都可导；在区域 D 解析，要求在 D 每一点解析。区域是开集，所以如果函数在区域中每点可导，它就在该区域解析。

把“一个点”和“附近一片区域”区分开来。解析一定推出该点可导，但一个点可导不保证存在这样的邻域。

课件例 4：f(z)=|z|² 在哪里可导和解析？

在原点，差商为 |Δz|²/Δz=Δz̄，随 Δz→0 趋于 0，所以 f′(0)=0。对于 z₀≠0，展开后差商为 z̄₀+z₀·Δz̄/Δz+Δz̄。沿实轴与虚轴趋近，第二项分别为 z₀ 和 −z₀，结果不同，故非零点不可导。

原点任何邻域都包含非零点，因此虽然原点可导，却在原点不解析；函数处处不解析。

奇点是相对于解析性说的

粗略地说，函数的奇点是它未解析的点。为了使用洛朗展开和留数，还必须进一步核对是否为孤立奇点：在某个去心邻域内函数处处解析，中心却不解析或无定义。非孤立奇点、支点等不能不加检查地套用孤立奇点定理。

补充例：1/z 的 0 点

函数在 0 无定义，在 0<|z|<1 内解析，所以 0 是孤立奇点。它并非“整个平面都不解析”：它在去掉 0 的平面处处解析。

判断流程与练习

先问定义域，再判断点可导，最后看附近是否存在整片可导的开邻域。找解析区域时，不能只写出满足某个方程的零散点。

1. f(z)=z² 在 0 解析吗？

解析。它在整个复平面可导，所以当然在 0 的任意足够小邻域内可导。

2. “在一点可导但不解析”可能吗？

可能；|z|² 在 0 正是反例。

3. 1/z 在 |z|>0 的区域解析吗？

是。每个非零点附近都能取到不含 0 的小邻域。

例题：分清定义域与解析区域

考虑 f(z)=1/(z²+1)。分母分解为 (z−i)(z+i)，因此原表达式在 ±i 无定义。除去这两点后，它是多项式的商，分母非零，故在每个剩余点的某个邻域解析。

答案：解析区域是 ℂ∖{i,−i}。判断时既不能把整个平面都写上，也不应因为两个奇点而否定其他地方的解析性。

补充练习：f(z)=z̄ 在哪里解析？

沿实轴和虚轴的差商分别为 1 和 −1，任何点都不可导，所以没有解析点。这个结论强于“不是整函数”。

补充例题：一个点的连续、可导和解析

定义 f(z)=z²（z≠0），f(0)=1。第一步：由于 z²→0，而 f(0)=1，所以 f 在 0 不连续。第二步：可导必连续，因此 f 在 0 不可导，更不解析。第三步：在任何非零点，都能取不含 0 的邻域；在该邻域内 f 与 z² 相同，故 f 在该点解析。

结论是：非零点解析，0 点不解析。重点是先检查分段定义与所求极限是否一致，而不是直接把多项式导数套到分段点。

自测与解析

1. f(z)=1/(z−2) 在 0 解析吗？

解析。在 0 附近可取半径小于 2 的圆盘，分母在其中不为零。

2. 函数在 0 可导，能否仅据此确定它在 0 解析？

不能，还需要某个邻域内每一点均可导。

3. 分段函数的 0 点函数值与邻近极限不同时，0 点可能可导吗？

不可能，因为此时不连续，而复可导必连续。
